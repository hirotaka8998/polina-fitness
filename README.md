# Сайт для Полины (MVP) — Персональные тренировки и бережный фитнес

Современный, минималистичный, высококонверсионный сайт-лендинг, разработанный в соответствии с ТЗ и набором скиллов (`landing-page`, `minimalist-ui`, `typography-first`, `seo-images`, `form-cro`, `telegram`, `analytics-tracking`).

---

## ⚡ Особенности реализации MVP

- **Mobile-First дизайн:** Выверенная модульная верстка от 360px до 4K, отсутствие горизонтального скролла, крупные кнопки под палец (от 48px).
- **Стиль и эстетика:** Премиальный «editorial/workspace» минимализм, нейтральная графитовая палитра (`#101114`) с одним спокойным акцентом (приглушенный бирюзовый/тиловый `#2DD4BF`), без кричащих кислотных плашек и стоковых штампов.
- **Шрифты:** Гротеск **Onest** (Google Fonts) с отличной поддержкой кириллицы и легким сканированием текста.
- **Оптимизация:** Легковесный чистый код без тяжелых библиотек, адаптивные картинки в формате WebP, ленивая загрузка (`loading="lazy"`), нулевой CLS.
- **Интеграция Telegram:** Код моментальной отправки заявок из формы в личный Telegram-бот или чат с поддержкой mock-режима (для локального тестирования и демо без боевого токена).
- **Яндекс.Метрика:** Базовый код счетчика + настроенные вызовы JavaScript-целей:
  - `telegram_button_click` — клик по любой кнопке перехода в Telegram.
  - `lead_form_submit` — успешная отправка формы записи.
- **Готовность к Vercel:** Проект не требует сборки (zero-config static site) и готов к мгновенному деплою на Vercel.

## 🚀 Как развернуть на Vercel

### Вариант 1: Через GitHub (Рекомендуемый)
1. Создайте репозиторий на GitHub и отправьте в него файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "feat: initial MVP release"
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
2. Зайдите на [vercel.com](https://vercel.com/) → нажмите **"Add New Project"** → выберите ваш репозиторий.
3. Нажмите кнопку **"Deploy"** (настройки сборки менять не нужно, проект статический). Сайт будет доступен через 20 секунд.

### Вариант 2: Через Vercel CLI
В корне проекта выполните:
```bash
npx vercel
```
Следуйте подсказкам в терминале.

## 🔧 Где настраиваются заглушки (Stubs)

### 1. Telegram-бот (получение заявок)
В файле [`main.js`](file:///c:/Users/aemec/OneDrive/Desktop/Сайт%20для%20Полины/main.js):
```javascript
const CONFIG = {
  // 1. Токен бота от @BotFather (например: '7123456789:AAH...')
  TELEGRAM_BOT_TOKEN: 'YOUR_BOT_TOKEN_HERE',
  
  // 2. ID вашего чата или личный ID от @userinfobot (например: '123456789')
  TELEGRAM_CHAT_ID: 'YOUR_CHAT_ID_HERE',

  // 3. Ваша прямая ссылка на Telegram для кнопок
  TELEGRAM_DIRECT_LINK: 'https://t.me/your_telegram_username'
};
```
> *По умолчанию включен **MOCK_MODE**: заявки успешно имитируют отправку и выводят отформатированный результат в консоль браузера, поэтому MVP можно тестировать на Vercel сразу без создания бота.*

### 2. Яндекс.Метрика
В файле [`index.html`](file:///c:/Users/aemec/OneDrive/Desktop/Сайт%20для%20Полины/index.html) в блоке `<head>` укажите ваш номер счетчика:
```javascript
window.YM_ID = 98765432; // Замените 0 на ваш реальный номер счетчика
```

### 3. Фотографии
В [`index.html`](file:///c:/Users/aemec/OneDrive/Desktop/Сайт%20для%20Полины/index.html) в блоках Hero и «О тренере» используются эстетичные временные фото с Unsplash в WebP. Замените ссылки на реальные фотографии Полины, когда они будут готовы.
